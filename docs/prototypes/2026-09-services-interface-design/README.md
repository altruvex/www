# Services › Interface Design — direction prototypes (2026-09-19)

Same process as `../2026-09-services-development`: an Awwwards Site-of-the-Day review first, then three
standalone scrollable prototypes with the same copy (from `serviceDetails.webDesign`) and the same real
screenshots of the live site. Unlike the development round, all three are painted in the house tokens from
the start (violet world, cool neutrals, 22/28/34 radii, pills, Outfit/Inter, serif-italic world clause) and
follow light/dark (toggle in the switcher). No 3D objects. Open directly: `open a.html`.

| file | direction | references | status |

The UI playground stays (Ali likes the idea), but reframed on 2026-09-19: it is "this site's own system" — how we build interfaces, and what each client gets designed for their product — never "the components we ship" or a component library for sale. Altruvex does not offer a UI component product yet; no direction may imply one.
