# About — direction prototypes (2026-09-30)

Three standalone, scrollable whole-page prototypes for /about, built after an Awwwards/award review.
Same copy and the same brand-mood images (`img/` = exports of `apps/www/public/brand/mood/*`); a switcher
at the bottom moves between them. Open directly (`open a.html`) or serve `docs/prototypes` (launch config
`prototypes`, port 4173). English-only, their own CSS — references, not production code.

| file | direction | idea sources | status |
|---|---|---|---|
| `a.html` | **The Letter**: display hero + four-fact record, one parallax mood photo, "01 The studio" founder letter whose words light up as you read + the Altr bracket (CMP-019), "02 The fine print" commitment ↔ cost clauses, signature, dark close | Kott Studio /about (01 The Studio / 02 The Fine Print), Ask Phill /about (origin story) | not chosen |
| `b.html` | **The Index**: split hero, 21:9 photo stage, four principles as a display-size open index (click to open body + cost), "who this is for / who it isn't" with struck lines, founder quote + one-line route, dark close | Lama Lama /about (SOTM Jul 2026, values as spine), Trionn /about ("who we're not for") | **Chosen** (Ali, 2026-09-30) — built into apps/www /about |
| `c.html` | **Chapters**: centred hero, three chapters (Why the name / How it runs / What you keep) scrolling beside a sticky photo that crossfades between three mood images, founder quote, dark close | The First The Last /about (text/photo rhythm), Floema /about (SOTM May 2026, mission, then story, then method) | not chosen |

Copy changes vs the live page: the ownership clause now reads "at final payment" (ToS §5), not "from day
one". "Who it isn't for" (B) and the "4 vs 1" route count (C) are new and have not been reviewed.
