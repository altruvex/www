# Services › Custom Development — direction prototypes (2026-09-19)

Three standalone, scrollable whole-page prototypes built after an Awwwards Site-of-the-Day review,
so a direction could be chosen by feel rather than from a written list. Same copy, same brand images;
a switcher at the bottom moves between them. Open any file directly in a browser (`open a.html`) —
the www dev server's CSP blocks the Google Fonts / cdnjs they load, so do not serve them from `public/`.

| file | direction | reference | status |
|---|---|---|---|
| `a.html` | **Blue Department** — full brand-blue world, stacked sticky commitment rows, tilted proof screenshot, handover object | PX Push (SOTD) | **Kept for later** — Ali wants this blue treatment applied to another surface he will name |
| `b.html` | **The Stack** — dark, layers assembling on a dotted spine ending at "Your account", rules list | Sui (SOTD) | not chosen |
| `c.html` | **Dark Studio** — 3D layered object, word-reveal statement, kinetic word track, assembling image tiles, key-facts cards | Trionn / Produx (SOTD) | **Chosen** for /services/development (built into the site with the house system) |

`img/` holds exports of `public/brand/branding/*` and `public/images/services/*` plus screenshots of the live site.
Prototypes are English-only and use their own CSS — they are references, not production code.
