Which Arabic face stands next to Outfit?

Three Arabic display faces, each set against the live Outfit 300 hero. The first row puts both scripts on one baseline at the same size — the Arabic should read as the same size as the English. Body copy stays Vazirmatn in every column. Ratio = Arabic tooth height ÷ Outfit x-height, measured from the font files (1.00 = equal).
