Altruvex Sans (Track A) — phase A.4 optical proof

Production stacks --stack-prod-en / --stack-prod-ar; spacing from dist/web/tokens.css. Latin tracking is the token whose size is the largest one at or below the font size (the token file's rule); Arabic is never tracked. Ink top / bottom = highest ink above and lowest ink below the alphabetic baseline, in em, from a 2x canvas raster (any pixel with alpha > 0; resolution 1 ÷ (2 × font size) em, so 0.021em at 24px). Density = ink ÷ (advance × font size), advance including tracking. AR÷EN = AR density ÷ EN density in the same block. AR weights are requested weights; "draws" is the drawn weight read from dist/build-report.json. Latin line height 1.2 is a page value (no Latin token exists).

2 · Display tracking by case (step 15)

One token per size and weight for every case; no case-specific tracking is applied.
